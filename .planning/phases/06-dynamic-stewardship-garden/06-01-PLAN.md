<objective>
Create the non-UI contracts for dynamic garden rendering: a stable slot map, plant asset manifest, and pure growth-stage calculation from weekly progress percentage.
</objective>

## Scope

- Add a small `src/modules/garden/` module.
- Define deterministic garden slots using percentage coordinates suitable for an isometric base image.
- Define a plant asset manifest that points to separate stage assets under `public/garden/plants/...`.
- Implement a pure `getPlantStage(progressPercent)` function with five stages.
- Add unit tests for boundary values: 0, partial, half, near-complete, complete, clamped negative, clamped over-100.

## Out Of Scope

- Dashboard rendering.
- Database schema changes.
- Asset editing/cropping beyond referencing final paths.
