Build a reusable `GardenCanvas` component that renders an empty garden base and overlays active mission plants as layered transparent images.
</objective>

## Scope

- Create a presentational component that accepts `plants` as props.
- Always render the empty base image.
- Render zero overlays when `plants.length === 0`.
- Render overlays by slot and stage when plants exist.
- Preserve the current dashboard's soft, child-friendly isometric visual language.
- Keep composition responsive in the existing `4/3` hero card.

## UI Notes

- Use exact positioned percentages, not hard-coded pixels tied to one screen width.
- Add subtle image outline/shadow only if it improves depth without visible halos.
- Avoid `transition: all`; animate only `opacity`, `transform`, or `filter` if animation is introduced.

## Verification

- Add component tests for empty and populated rendering.
- Run targeted test command for the component test once the project's component-test pattern is confirmed.
- Manually inspect mobile and desktop viewport screenshots or document why visual verification was deferred.
