# Phase 4 — UI Design Contract: Child Tasks

> Visual and interaction contract for Phase 4 (CTASK-01..05). Generated by gsd-ui-researcher, verified by gsd-ui-checker.

---

## Design System

| Property | Value |
|----------|-------|
| Tool | none — manual CSS tokens via `globals.css` `@theme` |
| Preset | not applicable |
| Component library | none (inline styles + CSS variables, pattern from Phases 1–3) |
| Icon library | SVG inline (no external icon library — source: design_handoff_kreds/README.md) |
| Font | Plus Jakarta Sans — weights 400, 500, 600, 700, 800 (already configured in Phase 1) |

**Pattern:** All components use inline `style={{...}}` with `var(--color-kreds-*)` CSS variables. Do NOT introduce Tailwind utility classes or a component library for Phase 4 — follow the pattern of `garden-view.tsx`, `garden-header.tsx`, etc.

## Spacing Scale

Declared values (all multiples of 4):

| Token | Value | Usage |
|-------|-------|-------|
| xs | 4px | Icon gaps, gap between check SVG and text |
| sm | 8px | Gap between task cards in list |
| md | 12px | Card internal padding (top/bottom) — source: design handoff "padding 12px 13px" |
| md-h | 13px | Card internal padding (left/right) — source: design handoff |
| lg | 16px | Section horizontal padding (matches existing GardenView `padding: '0 16px'`) |
| xl | 24px | Page top padding (matches existing `paddingTop: 24`) |
| 2xl | 32px | Gap between major sections (tasks → tithe → savings) |
| nav | 80px | Bottom nav height — fixed, source: CONTEXT.md D-03 / design handoff |

Exceptions:
- **Check button:** 38×38px — not on the 4px scale; this is a design handoff hard spec (CTASK-02). Do not adjust.
- **Bottom nav padding-bottom:** `80px` added to page container (already present in `garden-view.tsx` as `paddingBottom: 80`).
- **Touch target minimum:** 44px logical — check button (38×38px) must be wrapped in a 44×44px touch area (padding compensation) for accessibility.

**4 nav items:**

| Item | Label | Section target | Default |
|------|-------|---------------|---------|
| Jardim | "Jardim" | `#section-garden` (scroll to top) | Active on load |
| Tarefas | "Tarefas" | `#section-tasks` | — |
| Cofrinho | "Cofrinho" | `#section-savings` | — |
| Doar | "Doar" | disabled / placeholder | — |

**Active state:** icon stroke `#3E6B4F`, label `#3E6B4F`, weight 700.
**Inactive state:** icon stroke `#9AA092` (var: `--color-kreds-hint`), label `#9AA092`, weight 600.
**"Doar" item:** visually identical to inactive; `onClick` is a no-op; no `href`; `aria-disabled="true"`.

**IntersectionObserver:**
- Observe `#section-garden`, `#section-tasks`, `#section-savings`
- Whichever section has `intersectionRatio > 0` and is highest on screen sets the active icon
- Default (on load, before any scroll): "Jardim" is active
- Threshold: `[0, 0.1]` — fires as soon as any part enters viewport

**Scroll behavior:**
- Click on Jardim/Tarefas/Cofrinho: `element.scrollIntoView({ behavior: 'smooth', block: 'start' })`
- Scroll offset compensation: sections have `scroll-margin-top: 0` (bottom nav is fixed at bottom, not top — no offset needed)

**Icon spec (SVG inline, all 24×24px viewBox):**
- Jardim: house-plant or leaf silhouette — use existing garden icon pattern if available, otherwise simple leaf SVG
- Tarefas: checklist / checkbox-list SVG
- Cofrinho: piggy bank or coin-in-slot SVG
- Doar: hand-heart or gift SVG
- Stroke width: `1.5px` on all icons

## Accessibility

- Check button: `aria-label="Marcar tarefa: {task.title}"` when pending; `aria-label="Tarefa concluída: {task.title}"` when done; `aria-pressed={task.done}`
- Check button: `role="checkbox"` or `type="checkbox"` (not `<button>`)
- Task card: `<li>` inside `<ul aria-label="Lista de tarefas">`
- Tithe button: `aria-label="Plantar dízimo"` default; `aria-label="Dízimo plantado"` + `aria-disabled="true"` after click
- Savings card: `role="region" aria-label="Cofrinho"`, progress bar `role="progressbar" aria-valuenow={savings} aria-valuemax={goal} aria-valuemin={0}`
- Bottom nav: `<nav aria-label="Navegação principal">`, each item `<button>` with `aria-label`, `aria-current="page"` on active item
- "Doar" nav item: `aria-disabled="true"` + `tabIndex={-1}` (or keep focusable with tooltip — Claude's discretion)
