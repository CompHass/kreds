| Docker build → npm registry | pnpm install --frozen-lockfile in deps stage pulls from npm; lockfile pins exact versions |
| Docker container → host network | Container exposes PORT=3000; HOSTNAME="0.0.0.0" allows K8s probes but no secrets exposed |
| Testcontainers → Docker daemon | Integration tests require Docker socket access; containerized PostgreSQL is ephemeral and test-scoped |
