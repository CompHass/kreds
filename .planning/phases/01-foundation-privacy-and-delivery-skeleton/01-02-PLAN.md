<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Client → API Route | Untrusted HTTP requests hit /api/families; handler performs read-only query with no user input |
| App → PostgreSQL | DATABASE_URL contains credentials; must not leak to client bundle |
| Local Docker → Host | docker-compose exposes local PostgreSQL on port 5432 for development only |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Environment variables | mitigate | src/lib/db/index.ts reads DATABASE_URL only on server; no NEXT_PUBLIC secret names |
| T-01-02 | Information Disclosure | Database credentials in source control | mitigate | docker-compose uses development-only credentials matching .env.example; .env.local remains gitignored |
| T-01-07 | Tampering | Migration pipeline | mitigate | Migrations are generated by drizzle-kit from typed schema and applied to disposable local PostgreSQL; verification checks families table exists |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | No new package install in this plan; uses lockfile created after Plan 01-01 human verification |
</threat_model>
