       - Stage 1 (deps): ARG NODE_VERSION=24.13.0-slim, FROM node:${NODE_VERSION} AS deps, WORKDIR /app, COPY package.json pnpm-lock.yaml .npmrc* ./, RUN corepack enable pnpm && pnpm install --frozen-lockfile
       - Stage 2 (builder): FROM node:${NODE_VERSION} AS builder, WORKDIR /app, COPY --from=deps /app/node_modules ./node_modules, COPY . ., ENV NODE_ENV=production, RUN corepack enable pnpm && pnpm build
       - Stage 3 (runner): FROM node:${NODE_VERSION} AS runner, WORKDIR /app, ENV NODE_ENV=production, ENV PORT=3000, ENV HOSTNAME="0.0.0.0", COPY --from=builder --chown=node:node /app/public ./public, RUN mkdir .next && chown node:node .next, COPY --from=builder --chown=node:node /app/.next/standalone ./, COPY --from=builder --chown=node:node /app/.next/static ./.next/static, USER node, EXPOSE 3000, CMD ["node", "server.js"]

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| Docker build → npm registry | pnpm install --frozen-lockfile in deps stage pulls from npm; lockfile pins exact versions |
| Docker container → host network | Container exposes PORT=3000; HOSTNAME="0.0.0.0" allows K8s probes but no secrets exposed |
| Testcontainers → Docker daemon | Integration tests require Docker socket access; containerized PostgreSQL is ephemeral and test-scoped |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Environment variables in Docker build | mitigate | Multi-stage build ensures no .env files in final image; NODE_ENV=production in builder/runner stages; DATABASE_URL not baked into image — injected at runtime via K8s secrets |
| T-01-03 | Elevation of Privilege | Docker container execution | mitigate | Dockerfile runner stage uses `USER node` (non-root); no sudo or root capabilities; minimal base image (node:24.13.0-slim) |
| T-01-05 | Tampering | Docker build supply chain | mitigate | pnpm install --frozen-lockfile ensures exact dependency versions; no dynamic package resolution; lockfile committed to source control |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | All packages already verified in Plan 01 Task 2; frozen lockfile prevents substitution |
</threat_model>
