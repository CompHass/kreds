| Client → API Route | Untrusted HTTP requests hit /api/health; response is static, no user input processed |
| App → PostgreSQL | DATABASE_URL contains credentials; must not leak to client bundle |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-01 | Information Disclosure | Environment variables | mitigate | Zod env validation in src/lib/env.ts ensures DATABASE_URL is server-only; never prefix secrets with NEXT_PUBLIC_; only NEXT_PUBLIC_APP_URL is client-safe |
| T-01-02 | Information Disclosure | Database credentials in source control | mitigate | .gitignore includes .env.local and .env*.local; .env.example contains only placeholder values; DATABASE_URL read from process.env at runtime |
| T-01-03 | Elevation of Privilege | Docker container runtime | mitigate | Dockerfile runner stage uses `USER node` (non-root); HOSTNAME="0.0.0.0" for K8s probes; no secrets baked into image |
| T-01-04 | Information Disclosure | Child data collection | mitigate | Phase 1 collects ZERO child data; families table contains only name/timezone/audit columns; PRIVACY-INVENTORY.md (Plan 03) documents all future child data categories before any collection begins |
| T-01-SC | Tampering | npm/pip/cargo installs | mitigate | Blocking human checkpoint (Task 2) verifies all 16 [ASSUMED] packages on npmjs.com before pnpm install; no auto-approval |
</threat_model>
