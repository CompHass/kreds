<objective>
Wire the child session middleware, deliver the child home page as the first authenticated child surface, and surface login audit events in the guardian timeline.

Purpose: D-32 requires child routes to be scoped strictly to childProfileId — a child session cannot access family-wide data. D-33 requires guardians to see child last-login in the audit timeline. This plan closes the full auth loop: child logs in (plan 02-11), arrives at home page (this plan), guardian sees the event (this plan).

Output: requireChildSession server helper; /child/home page (gated by child JWT); guardian audit page updated to show child_login events and last_accessed_at per child profile.
</objective>

## Phase Goal

**As a** child, **I want to** land on my personal home page after entering my PIN **so that** I can see my Kreds balance and tasks, while my guardian can verify I logged in through the audit timeline.

<threat_model>
## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| child-session JWT → child pages | JWT verificado server-side em toda rota child; falha → redirect sem expor dados |
| child page → DB | Queries filtradas exclusivamente por childProfileId; familyId da sessão não usado para enumeração |
| guardian audit page → child login events | Eventos já sanitizados por createAuditEvent; nenhum dado de PIN ou hash exposto no audit log |

|-----------|----------|-----------|-------------|-----------------|
| T-02-12-01 | Elevation of Privilege | /child/home page | mitigate | requireChildSession verifica JWT e role='child'; falha redireciona para / sem revelar conteúdo |
| T-02-12-02 | Information Disclosure | child home queries | mitigate | SELECT usa childProfileId como único filtro — never family_id para enumerar outros filhos |
| T-02-12-03 | Repudiation | child login events | mitigate | child_login_success e child_login_failed escritos em child-auth endpoint (plano 02-11); imutáveis em family_audit_events |
| T-02-12-04 | Spoofing | requireChildSession | mitigate | Chama verifyChildSession (jose.jwtVerify) — valida assinatura HS256 com CHILD_SESSION_SECRET |
| T-02-12-05 | Information Disclosure | guardian audit last_accessed_at | accept | Guardian ver timestamp de último acesso é comportamento desejado (D-33); não expõe PIN ou conteúdo da sessão |
