## Trust Boundaries

Nenhuma. Esta fase renderiza um RootLayout e uma página placeholder estáticos, sem entrada de usuário, formulários, autenticação ou chamadas de rede dinâmicas. A fonte é auto-hospedada via `next/font` (sem request externo ao Google em runtime — ganho de privacidade). Não há fronteira de confiança cruzada.

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-01-02-I | Information Disclosure | next/font/google (Plus Jakarta Sans) | mitigate | `next/font/google` baixa a fonte em build time e a serve localmente — elimina o request ao Google Fonts em runtime e o vazamento de IP/User-Agent do usuário para um terceiro. Mitigação já embutida na escolha de stack (RESEARCH Pattern 2). |
| T-01-02-D | Denial of Service | pnpm build | accept | Build local determinístico sem entrada externa não confiável; falha de build é detectada na verificação automatizada, não em produção. |
| T-01-02-SC | Tampering | npm/pnpm installs | accept | Nenhum pacote novo instalado — `next/font` é built-in do `next` 16.2.7 (já auditado em RESEARCH Package Legitimacy Audit). Sem gate de legitimidade necessário. |

ASVS L1: fase é CSS/layout estático — categorias V2–V6 não se aplicam (confirmado em 01-RESEARCH.md Security Domain). Block-on: nenhuma ameaça de alta severidade identificada.
