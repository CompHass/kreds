    Imports: `import { cookies } from 'next/headers'`, `import { db } from '@/lib/db'`, `import { childProfiles } from '@/lib/db/schema'`, `import { eq } from 'drizzle-orm'`, `import { checkBruteForce, recordFailedAttempt, resetAttempts, signChildSession } from '@/lib/families/child-session'`, `import { verifyPin } from '@/lib/families/child-pin'`.

    Exportar `async function verifyChildPin(childId: string, pin: string)`:
    1. `const bf = checkBruteForce(childId)`; se `bf.blocked` → `return { error: 'blocked' as const }` (D-09: 5 tentativas).
    2. Buscar pinHash: `const [child] = await db.select({ pinHash: childProfiles.pinHash, familyId: childProfiles.familyId }).from(childProfiles).where(eq(childProfiles.id, childId)).limit(1)`. (Buscar pinHash E familyId numa única query — otimização vs RESEARCH que fazia 2 queries.)
    3. Se `!child?.pinHash` → `return { error: 'no-pin' as const }`.
    4. `const valid = await verifyPin(pin, child.pinHash)`; se `!valid` → `recordFailedAttempt(childId); return { error: 'invalid' as const }`.
    5. `const jwt = await signChildSession({ childProfileId: childId, familyId: child.familyId, role: 'child' })`.
    6. `resetAttempts(childId)`.
    7. `const cookieStore = await cookies()` (Pitfall 4: async). `cookieStore.set('child-session', jwt, { httpOnly: true, sameSite: 'lax', secure: process.env.NODE_ENV === 'production', path: '/', maxAge: 8 * 60 * 60 })` (D-14 locked: nome child-session, httpOnly, sameSite lax, secure em prod).
    8. `return { success: true as const }`.

    NÃO hashar PIN no cliente — o action recebe plaintext e verifica server-side. NÃO usar API route (D-07: Server Action).
