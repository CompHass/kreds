    NÃO importar `@/lib/env` (Edge runtime não suporta) — usar `process.env.CHILD_SESSION_SECRET!` diretamente (RESEARCH Pitfall: env.ts não funciona no Edge). NÃO chamar `auth()` aqui (só verifica next-auth, não child-session). NÃO usar `next/headers` cookies() (Edge usa `req.cookies`).

    Constante: `const CHILD_SESSION_COOKIE = 'child-session'`.
    Helper `nextAuthCookieName(url: string): string` — retorna `url.startsWith('https') ? '__Secure-authjs.session-token' : 'authjs.session-token'` (Pitfall 2: nome do cookie muda por protocolo).

    `export async function middleware(req: NextRequest)`:
    - Extrair `const { pathname } = req.nextUrl` e `const url = req.url`.
    - Rotas públicas pass-through (`NextResponse.next()`) quando: `pathname === '/'` OU `pathname.startsWith('/api/auth/')` OU `pathname.startsWith('/api/child/')` OU `pathname.startsWith('/family/access/')`. ORDEM IMPORTA: `/family/access/` deve ser checado ANTES da regra genérica `/family/`.
    - Branch `/child/`: se `pathname.startsWith('/child/')` — pegar `req.cookies.get(CHILD_SESSION_COOKIE)?.value`. Se ausente → `NextResponse.redirect(new URL('/', req.url))`. Se presente, `try`: `const secret = new TextEncoder().encode(process.env.CHILD_SESSION_SECRET!)`; `const { payload } = await jwtVerify(cookieValue, secret)`; se `payload.role !== 'child'` → redirect para `new URL('/family/access/' + payload.familyId, req.url)`; senão `NextResponse.next()`. No `catch`: tentar `decodeJwt(cookieValue)` para extrair `familyId`; se decodificável e familyId presente → redirect `/family/access/${familyId}`; senão (malformado) → redirect `/`.
    - Branch `/family/` ou `/guardian/`: `if (pathname.startsWith('/family/') || pathname.startsWith('/guardian/'))` — pegar `req.cookies.get(nextAuthCookieName(url))?.value`. Ausente → `NextResponse.redirect(new URL('/api/auth/signin', req.url))`. Presente → `NextResponse.next()`. NÃO decriptar o JWT do next-auth (Pitfall: middleware faz cookie-check heurístico, não decripta — exigiria AUTH_SECRET).
    - Fallback final: `return NextResponse.next()`.

    `export const config = { matcher: ['/((?!_next/static|_next/image|favicon.ico|.*\\.png|.*\\.svg|sw\\.?js).*)'] }` (deve casar regex `/sw\\?\.js/i` do teste — note o `sw\\.?js`).
