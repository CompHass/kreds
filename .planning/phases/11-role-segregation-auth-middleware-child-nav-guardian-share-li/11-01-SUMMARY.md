4. **donations** table:
   - UUID primary key (`id`)
   - Foreign keys: `familyId` → families, `childProfileId` → childProfiles
   - `targetLabel` (text) — donation description
   - `amountKreds` (integer)
   - `status` (enum, default 'pending')
   - `requestedAt`, `approvedAt` (timestamps)
   - Indexes: familyId, childId
   - **Check constraint:** `donation_amount_positive` — `amountKreds > 0`
