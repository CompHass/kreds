    Função isPublicPath(pathname: string): boolean
    - Retorna true se pathname === '/' OU pathname.startsWith(prefixo + '/') para qualquer prefixo em PUBLIC_PREFIXES
    - ATENÇÃO: '/family/access/[familyId]' é público mas '/family/children' não é

    Função extractFamilyIdFromToken(token: string): string | null
    - Propósito: extrair familyId para redirect quando o token existe mas falhou na verificação.
    - Usa decodeJwt(token) do jose (decodifica sem verificar assinatura).
    - Retorna payload.familyId como string se presente e válido (typeof === 'string').
    - Qualquer exceção (token malformado, não é JWT) → return null.
    - IMPORTANTE: este valor é usado APENAS para routing de redirect, nunca para autorização.

    Função async middleware(request: NextRequest):
    1. const { pathname } = request.nextUrl
    2. Se isPublicPath(pathname) → return NextResponse.next()
    3. Se pathname.startsWith('/child/'):
       a. Ler token = request.cookies.get(CHILD_SESSION_COOKIE)?.value
       b. Se !token → redirect para new URL('/', request.url)
       c. Try: const secret = new TextEncoder().encode(process.env.CHILD_SESSION_SECRET)
          const { payload } = await jwtVerify(token, secret)
          if (payload.role !== 'child') throw new Error('not child')
          return NextResponse.next()
       d. Catch (token inválido/expirado/role errado):
          const familyId = extractFamilyIdFromToken(token)
          if (familyId) return NextResponse.redirect(new URL('/family/access/' + familyId, request.url))
          return NextResponse.redirect(new URL('/', request.url))
    4. Se pathname.startsWith('/family/') OU pathname.startsWith('/guardian/'):
       a. isSecure = request.url.startsWith('https')
       b. cookieName = isSecure ? NEXTAUTH_COOKIE_PROD : NEXTAUTH_COOKIE_DEV
       c. Se request.cookies.get(cookieName)?.value ausente → redirect para new URL('/api/auth/signin', request.url)
       d. return NextResponse.next()
    5. Fallthrough: return NextResponse.next()
