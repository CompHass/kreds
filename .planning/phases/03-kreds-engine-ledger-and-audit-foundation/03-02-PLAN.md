## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| HTTP body → EarningCommandSchema | amount deve ser inteiro positivo; familyId/childProfileId devem ser UUIDs válidos — Zod valida |
| caller → commandId | commandId deve vir do caller (não gerado no server) para idempotência real end-to-end |
| API route → engine | family_id do caller deve coincidir com family do childProfileId — verificação ausente neste plano; adicionada na Fase 2 wiring |
