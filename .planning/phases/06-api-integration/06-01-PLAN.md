    Define three interfaces (not exported — implementation detail):

    ```
    interface EarningCommand {
      commandId: string
      familyId: string
      childProfileId: string
      guardianIdentityId: string
      amount: number
      note?: string
    }

    interface AdjustmentCommand {
      commandId: string
      familyId: string
      childProfileId: string
      guardianIdentityId: string
      amount: number
      reason: string
    }

    interface ReversalCommand {
      commandId: string
      familyId: string
      childProfileId: string
      guardianIdentityId: string
      correctsTransactionId: string
      correctionNote: string
    }
    ```

    Implement and EXPORT:

    `postEarning(cmd: EarningCommand)` — db.transaction() that:
    1. Inserts ledgerTransactions with commandId, familyId, childProfileId, transactionType='task_earning', initiatedByIdentityId=cmd.guardianIdentityId, note=cmd.note. Use .returning() to get the inserted row.
    2. Calculates firstfruits = calculateFirstfruits(cmd.amount); available = cmd.amount - firstfruits.
    3. Inserts two ledgerLines: {transactionId: txn.id, childProfileId, accountType: 'available', amount: available} and {transactionId: txn.id, childProfileId, accountType: 'firstfruits', amount: firstfruits}.
    4. Returns the transaction header row.

    `postNegativeAdjustment(cmd: AdjustmentCommand)` — db.transaction() that:
    1. Inserts ledgerTransactions with commandId, familyId, childProfileId, transactionType='negative_adjustment', initiatedByIdentityId=cmd.guardianIdentityId, note=cmd.reason. Use .returning().
    2. Inserts ONE ledgerLine: {transactionId, childProfileId, accountType: 'available', amount: -cmd.amount} (negative value).
    3. Returns the transaction header.

    `postReversal(cmd: ReversalCommand)` — db.transaction() that:
    1. Fetches the original transaction: db.select from ledgerTransactions where id=cmd.correctsTransactionId.
    2. If the original transaction's familyId !== cmd.familyId, throws new Error('cross_family_reversal_forbidden').
    3. Fetches original ledgerLines for that transactionId.
    4. Inserts new ledgerTransactions with commandId, familyId, childProfileId, transactionType='reversal', initiatedByIdentityId=cmd.guardianIdentityId, correctsTransactionId=cmd.correctsTransactionId, note=cmd.correctionNote. Use .returning().
    5. Inserts reversed lines: for each original line, insert {transactionId: newTxn.id, childProfileId, accountType: line.accountType, amount: -line.amount}.
    6. Returns the new transaction header.

    CRITICAL — Do NOT call revalidatePath inside transactions. Do NOT catch 23505 in the engine — let it propagate (the route handler catches it). The test verifies `await expect(postEarning(command)).rejects.toMatchObject({ code: '23505' })`.

    CREATE src/lib/cycles/current-cycle.ts — First line: `import 'server-only'`.

    Export `getCurrentCycleStart(): string` that:
    1. Gets `const now = new Date()`.
    2. Gets `const dayOfWeek = now.getUTCDay()` (0=Sunday, 6=Saturday).
    3. Creates `const sunday = new Date(now)` and sets `sunday.setUTCDate(now.getUTCDate() - dayOfWeek)`.
    4. Returns `sunday.toISOString().slice(0, 10)` — yields 'YYYY-MM-DD'.

    If today is Sunday, dayOfWeek=0, daysBack=0 — returns today. If today is Saturday, dayOfWeek=6, daysBack=6 — returns last Sunday.
