## Trust Boundaries

| Boundary | Description |
|----------|-------------|
| env → server module | PIN_ENCRYPTION_KEY crosses from process env into the cipher; must never reach client |
| plaintext PIN → stored ciphertext | reversible AES-GCM material at rest in child_profiles.pin_encrypted |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-08-01 | Information Disclosure | pin-cipher.ts / PIN_ENCRYPTION_KEY | mitigate | `import 'server-only'` on pin-cipher.ts; key read only inside getKey(); acceptance criterion greps out any bcrypt/client leakage |
| T-08-02 | Tampering | AES-GCM ciphertext at rest | mitigate | GCM auth tag verified on decrypt with explicit authTagLength=16; test asserts tampered ciphertext throws |
| T-08-03 | Tampering | IV reuse across encryptions | mitigate | fresh randomBytes(12) per encryptPin call; test asserts two encryptions differ (Pitfall 3) |
| T-08-04 | Denial of Service | missing/malformed PIN_ENCRYPTION_KEY at runtime | mitigate | eager envSchema.parse validation fails at boot, not at first reveal (Pitfall 4) |
| T-08-05 | Elevation of Privilege | cross-family child profile mutation | mitigate | every child-profiles.ts mutation scoped by `and(eq(id), eq(familyId))` |
| T-08-SC | Tampering | npm installs (this plan adds none) | accept | no new packages installed in Plan 01; radix-ui install + legitimacy handled in Plan 04 |
