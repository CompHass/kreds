## Interaction States

### TaskToggle (PTASK-04)
- Estado ativo: bg `#3E6B4F`, knob posição direita (`left: 20px`)
- Estado inativo: bg `#D7DBCC`, knob posição esquerda (`left: 3px`), card fica `opacity: 0.5`
- Transição knob: `left .2s ease`
- Toggle é independente do lápis — não abre painel de edição

### EditButton / Modo Edição (PTASK-04, PTASK-06, D-06, D-08)
- Clicar lápis: carrega dados da tarefa no painel direito, card recebe destaque (bg `#F4F8F2`, border `#3E6B4F`)
- Modo edit ativo: botão lápis fica "ativo" (border + stroke verdes)
- Cancelar (X no cabeçalho do form): restaura painel para estado idle, remove destaque do card

### FormCTA (PTASK-06)
- Habilitado: ≥1 criança selecionada → label "Adicionar tarefa" (create) ou "Salvar alterações" (edit)
- Desabilitado: nenhuma criança selecionada → label "Selecione uma criança", bg `#C2C9BC`, `cursor: not-allowed`

### FilterChips (PTASK-03)
- "Todas" sempre presente como primeira opção
- Chip selecionado: bg `#3E6B4F`, texto branco
- Chip não selecionado: bg `#FBFAF5`, border `#E2DECF`, texto `#27372C`
- Apenas um chip ativo por vez

### DeleteButton (PTASK-10, D-06)
- Visível somente em modo edit (tarefa existente)
- Invisível em modo create ou idle
- Clique: remove tarefa do array local imediatamente (sem modal de confirmação — padrão definido em design handoff §Interações)
- Hover: bg muda de `#FBF1EC` → `#F6E4DC`

## Accessibility Notes

- Sidebar nav icons: `aria-label` obrigatório em cada botão (sem texto visível)
- TaskToggle: `role="switch"`, `aria-checked`, `aria-label="Ativar/desativar tarefa: {título}"`

- FilterChips: `aria-pressed={selected}` em cada chip
- RecurrencePills: `aria-pressed={selected}` em cada pill
- FormCTA desabilitado: `aria-disabled="true"`, `disabled` attr
- DeleteButton: `aria-label="Excluir tarefa"` + ícone `aria-hidden="true"`
- Painel direito com foco gerenciado: ao entrar em modo edit, mover foco para o campo título
