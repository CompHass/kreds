<threat_model>
## Trust Boundaries

| Boundary | Descrição |
|----------|-----------|
| Cliente HTTP → PATCH /api/families/tasks/:id | params.id vem da URL; body.action do cliente |
| URL params → template id | Guardian poderia tentar deactivate de id pertencente a outra família |
| Server → Intl API | timezone string vem do DB (families.timezone) — não do cliente |
| Página SSR → DB | Cálculo de ciclo é server-side; cliente não pode manipular cycleStart/cycleEnd |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-08 | Tampering | PATCH desativa template de outra família | mitigate | deactivateTaskTemplate sempre inclui eq(familyId, familyId) no WHERE — se id não pertence à família, update afeta 0 rows silenciosamente sem expor o error |
| T-04-09 | Elevation of Privilege | Filho chama PATCH deactivate | mitigate | Handler verifica membership.role === 'guardian'; retorna 403 se role for 'child' |
| T-04-10 | Tampering | Timezone manipulação via client | mitigate | timezone lido de families.timezone no DB (server-side), nunca do request do cliente; Intl lança TypeError para timezone inválida (capturado em try/catch) |
| T-04-11 | Information Disclosure | /family/tasks/current expõe tasks de outra família | mitigate | getActiveTasksForFamily sempre filtra por familyId derivado da sessão Auth.js |
| T-04-12 | Information Disclosure | deactivated_at exposto na página current | accept | Página current não exibe deactivated_at nem is_active — apenas título e kredsValue para guardian |
| T-04-SC | Tampering | npm installs | accept | Nenhum pacote novo — zero risco de supply chain |

</threat_model>
