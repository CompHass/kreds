## Phase Goal

**As a** guardian, **I want to** ver as tarefas ativas da semana atual organizadas pelo ciclo domingo-sábado da minha família, **so that** eu saiba o que meus filhos precisam concluir esta semana.

<feature>
  <name>getCycleForDate — computação pura de ciclo semanal (ACT-02)</name>
  <files>src/modules/activity/cycle.ts, src/modules/activity/__tests__/cycle.test.ts</files>
  <behavior>
    Dado qualquer Date UTC e uma timezone IANA:
    - Retorna cycleStart = domingo 00:00:00.000 local em UTC
    - Retorna cycleEnd = sábado 23:59:59.999 local em UTC (= cycleStart + 7*24*60*60*1000 - 1 ms)
    - América/São Paulo (UTC-3): input 2026-06-10T12:00Z → cycleStart 2026-06-07T03:00:00.000Z
    - América/São Paulo: cycleEnd → 2026-06-14T02:59:59.999Z
    - Quando input É a meia-noite local de domingo: retorna o mesmo ciclo (não avança)
    - Asia/Kolkata (UTC+5:30): cycleStart deve ser num domingo quando formatado com Intl
    - Fronteira de ano (quinta-feira 2026-01-01 SP): cycleStart em dezembro 2025
    - Fronteira de mês: dia negativo em Date.UTC é normalizado pelo runtime (não crashar)
    - América/New_York (UTC-4 verão): cycleStart correto para esse offset
    - Função não acessa DB, filesystem, rede ou qualquer side-effect
    - Assinatura: getCycleForDate(date: Date, timezone: string): { cycleStart: Date; cycleEnd: Date }
  </behavior>
  <implementation>
    Criar src/modules/activity/ com index barrel se não existir.
    Implementar cycle.ts usando exclusivamente Intl API nativa (zero imports externos):
    Step 1: Intl.DateTimeFormat com { timeZone, weekday: 'short', year: 'numeric', month: '2-digit', day: '2-digit' }.formatToParts para extrair localDow, localYear, localMonth0, localDay.
    Step 2: Intl.DateTimeFormat com { timeZone, timeZoneName: 'shortOffset' }.formatToParts para extrair offsetMs via regex /GMT([+-])(\d+)(?::(\d+))?/.
    Step 3: cycleStart = new Date(Date.UTC(localYear, localMonth0, localDay - localDow) - offsetMs). Date.UTC normaliza dias negativos automaticamente.
    Step 4: cycleEnd = new Date(cycleStart.getTime() + 7 * 24 * 60 * 60 * 1000 - 1).
    Exportar como named export (não default). Zero imports de @/lib/db ou drizzle-orm.
  </implementation>
</feature>
