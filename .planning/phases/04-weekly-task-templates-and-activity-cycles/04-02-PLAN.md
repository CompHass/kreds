<threat_model>
## Trust Boundaries

| Boundary | Descrição |
|----------|-----------|
| Cliente HTTP → POST /api/families/tasks | Input não confiável: title, kredsValue, assignedChildId do body |
| Cliente HTTP → family_id | Nunca aceitar family_id do cliente; derivar de Auth.js session |
| Browser → assignedChildId | Poderia forjar UUID de outra família |
| Server → DB | Queries devem sempre incluir family_id no WHERE |

## STRIDE Threat Register

| Threat ID | Category | Component | Disposition | Mitigation Plan |
|-----------|----------|-----------|-------------|-----------------|
| T-04-03 | Tampering | assignedChildId forjado no POST | mitigate | Antes do insert: SELECT child_profiles WHERE id=assignedChildId AND family_id=familyId; throw se vazio — garante que o filho pertence à família |
| T-04-04 | Information Disclosure | GET /api/families/tasks sem family_id | mitigate | Handler deriva familyId de membership.familyId (Auth.js session); cláusula WHERE obrigatória — FAM-05 |
| T-04-05 | Tampering | kredsValue float/negativo injetado | mitigate | taskTemplateSchema.safeParse com z.coerce.number().int().positive() + DB CHECK kreds_value > 0 |
| T-04-06 | Elevation of Privilege | Filho chama POST /api/families/tasks | mitigate | requireAuthenticatedIdentity valida sessão; membership lookup confirma role guardian antes de criar template (verificar role === 'guardian' no membership) |
| T-04-07 | Tampering | CSRF em POST (form HTML method="POST") | mitigate | Next.js App Router CSRF: Content-Type: application/json em API routes rejeita form encoding ingênuo; adicionar verificação Origin header em production ou migrar para Server Actions |
| T-04-SC | Tampering | npm installs | accept | Nenhum pacote novo — zero risco de supply chain |

</threat_model>
