# Sketch 001: Sylvan Visual System

## Design Question

Should Kreds move from dark neo-glass to the light Sylvan Growth visual language as the default design system?

## How to View

open .planning/sketches/001-sylvan-visual-system/index.html

## Variants

- **A: Full Sylvan** — Fully adopts the new light organic garden language. **Winner.**
- **B: Hybrid Glass Garden** — Keeps some translucent app-like glass and subtle dark contrast from earlier sketches.
- **C: Parent-Safe Premium** — More restrained, trustworthy, and adult-friendly while preserving organic tokens.

## Decision

Use **A: Full Sylvan** as the default child-facing visual direction. Parent and ledger surfaces can still borrow restraint from the other variants, but the product should lead with the light organic garden language.

## What to Look For

Compare whether the new Sylvan system should become the product default, whether we need a hybrid for parent screens, and whether the golden firstfruits symbol remains visually special without overwhelming the UI.
