# Sketch Manifest

## Design Direction

Use the Stitch `Sylvan Growth System` as the current design direction: a light organic garden language with deep forest greens, warm gold for firstfruits, milky glass cards, rounded living shapes, and growth/care metaphors.

Child screens should lead with warmth and clarity. Parent and history surfaces should preserve explicit financial trust. Generosity and gratitude should feel guided without guilt.

## Key Decisions

- Kreds do Bem copy must continue to avoid real-money donation implications in v1.
- Sylvan Growth is the selected visual direction because it naturally supports garden, tree, seed, fruit, firstfruits, dreams, and gratitude metaphors.
- Golden basket imagery should remain reserved for firstfruits so the symbol stays meaningful and does not become a generic reward icon.
- Full Sylvan is the selected default visual direction for child-facing screens.
- The main child dashboard should use the Garden Map model as the primary composition.
- The child-facing mission completion moment should use the Tree Growth Ceremony pattern, with ledger clarity available in parent/history contexts.
