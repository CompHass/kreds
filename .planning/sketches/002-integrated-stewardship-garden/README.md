# Sketch 002: Integrated Stewardship Garden

## Design Question

What should the child home dashboard become when missions, firstfruits, generosity, savings, and gratitude live in one garden metaphor?

## How to View

open .planning/sketches/002-integrated-stewardship-garden/index.html

## Variants

- **A: Garden Map** — A spatial garden where each stewardship area is a living plot. **Winner.**
- **B: Today First** — A task-focused dashboard with garden progress around the daily routine.
- **C: Stewardship Rings** — A compact mobile-first layout organized by firstfruits, giving, saving, and gratitude.

## Decision

Use **A: Garden Map** as the primary child dashboard model. Keep the daily routine clarity from B and the compact mobile patterns from C as secondary responsive behaviors.

## What to Look For

Choose the layout that makes stewardship feel integrated without hiding the weekly responsibility cadence or financial integrity model.
